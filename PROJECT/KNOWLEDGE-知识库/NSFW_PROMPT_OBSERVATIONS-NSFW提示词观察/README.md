# NSFW Prompt Observations
# NSFW 提示词工程观察

本目录用于记录 MiniMax H3 NSFW Prompt 的工程观察、失败模式和实验候选。

## 允许记录

- Prompt wording 观察
- Action / motion 执行观察
- State continuity 观察
- Temporal continuity 观察
- Reference Mapping 观察
- Camera / POV 观察
- Facial / expression 观察
- Wetness / liquid / surface continuity 观察
- 实测失败模式
- A/B 实验候选

## 不自动升级

本目录中的任何记录默认属于：

`OBSERVATION` 或 `EXPERIMENTAL`

除非有明确证据和用户批准，不得自动升级为：

- Skill 默认规则
- Universal Rule
- Framework
- Gate
- Layer
- 默认 Prompt 内容
