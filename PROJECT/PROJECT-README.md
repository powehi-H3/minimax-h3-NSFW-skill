# H3NSFW-Prompt-Project — 项目总览

## 项目目标

本项目用于协作开发、编写、优化、测试和正式收录 MiniMax H3 Prompt。

核心资产包括：

- V1-5 Frozen Skill Baseline
- Prompt Writing 任务
- Skill Optimization 研究任务
- 外部 Skill Research
- Prompt 测试与版本记录
- 正式 Prompt Library

## 当前 Baseline

**V1-5 Frozen。**

除非用户明确批准，否则不修改 V1-5 Skill，不创建 V1-6，不新增架构层级。

## 两个工作层级

### 项目协作层

负责：

- AI 角色
- 权限
- SOURCE / REVIEW / CANDIDATE / DRAFT / TEST / FINAL 生命周期
- GitHub 文件组织
- 决策与批准
- 新 AI 入职

### H3 Prompt Skill 层

负责：

- H3 六段结构
- Reference Semantics
- PATCH / PRESERVE
- Semantic Addition
- Multi-Ref
- Retention
- Execution Enrichment
- 以及 V1-5 已冻结的其他 Skill 内容

项目协作层不得冒充 H3 Skill；H3 Skill 也不承担 AI 团队管理职责。

## 最终决策权

用户拥有最终批准权，包括：

- 是否采用某个 Prompt 修改
- 是否正式收录 Prompt
- 是否采用 Research Candidate
- 是否修改 Skill
- 是否修改项目协作协议
