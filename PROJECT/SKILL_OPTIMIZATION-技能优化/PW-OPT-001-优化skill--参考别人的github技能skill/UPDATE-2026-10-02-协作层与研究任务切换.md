### Creative Enhancement 概念已经修正

此前对 Creative Enhancement 的理解存在偏差。

正确理解是：

**Creative Enhancement = 剧情 / 叙事 / 镜头创意提升。**

不是 Prompt 格式创意。

因此必须区分两个阶段：

#### Prompt Execution / Compilation

用户已经确定剧情时：

- 严格执行用户授权语义
- 不擅自增加剧情
- 不自动改写成另一套故事

#### Narrative Creative Enhancement

只有用户明确要求：

- 丰富剧情
- 增加张力
- 设计镜头节奏
- 提供剧情方案
- 帮助构思

时，才进入剧情 / 叙事创意阶段。

可研究的方向包括：

- Dramatic Tension Arc
- Visual Subtext & Micro-Beats
- Pacing & Shot Escalation

这些仍属于可选的创意阶段能力，不是默认强制规则。
